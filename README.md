# Bidwell Auction Marketplace

An auction marketplace built with TanStack Start. Public visitors can browse auctions;
signed-in users can save items, create listings, and place bids. Listings, watchlists, and
bids are stored in **MySQL**. Payments are not connected, and the admin workspace remains a
non-persistent demo.

## Stack

- TanStack Start v1 (React 19, file-based routing, Vite)
- TypeScript
- Tailwind CSS v4
- shadcn/ui primitives (Radix UI) + lucide-react icons
- MySQL 8 + Drizzle ORM
- Better Auth (email/password; optional Google OAuth)
- Vitest + Testing Library for tests

## Getting started

Requires Node.js 20+ and MySQL 8.

```sh
npm install
Copy-Item .env.example .env
# Edit DATABASE_URL (user, password, database name) and BETTER_AUTH_SECRET in .env
npm run db:setup
npm run dev
```

Open [http://localhost:8080](http://localhost:8080). Click **Sign in** and create an account
with email and password (minimum 8 characters). The first app load seeds sample auctions into
an empty database.

Optional Google OAuth: set `GOOGLE_CLIENT_ID` and `GOOGLE_CLIENT_SECRET`, and add
`http://localhost:8080/api/auth/callback/google` as an authorized redirect URI in Google Cloud Console.

Other scripts:

```sh
npm run db:setup     # create database + tables (safe to rerun)
npm run build        # production build
npm run preview      # serve the production build locally
npm run test         # run the test suite
npm run lint         # ESLint
npm run format       # Prettier
```

## Project layout

```
src/
  routes/                   pages (browse, auction detail, bids, watchlist, sell, admin)
  components/auction/       UI, client store, seller/admin workspaces
  db/                       MySQL schema, connection, setup script
  lib/auction-api.ts        server functions (bids use row locks in transactions)
  lib/auth.server.ts        Better Auth configuration
```

## Notes

- `src/routeTree.gen.ts` is generated by TanStack Router — don't edit it by hand.
- Sample listings and photos are in `src/components/auction/initial-data.ts`.
- Production builds use the Nitro Node server preset for MySQL connectivity.
